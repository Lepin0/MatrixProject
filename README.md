# 🧮 Complex Matrix Library in Java

Консольное объектно-ориентированное приложение на Java для работы с матрицами, элементы которых являются **комплексными числами**. Проект разработан как универсальная библиотека линейной алгебры с поддержкой базовых и продвинутых математических операций.

---

## ✨ Основные возможности

### 1. Комплексная арифметика (`Complex`)
* Представление комплексного числа в виде вещественной ($Re$) и мнимой ($Im$) частей.
* Корректное умножение и деление комплексных чисел с учетом специфики мнимой единицы ($i^2 = -1$).
* Автоматическое форматирование вывода (`toString`) с округлением до двух знаков после запятой и аккуратным отображением знаков.

### 2. Матричные операции (`Matrix`)
* **Базовое управление:** создание матриц произвольной размерности, безопасная установка элементов по индексам.
* **Сложение и вычитание:** поэлементные операции над матрицами одинаковых размеров с проверкой размерности.
* **Транспонирование:** зеркальное отражение матрицы относительно главной диагонали.
* **Умножение на скаляр:** масштабирование всей матрицы на заданное комплексное число.
* **Умножение матриц:** классическое матричное умножение ($A \cdot B$) с использованием комплексной арифметики.

### 3. Продвинутая линейная алгебра
* **Вычисление определителя ($\det$):** универсальный рекурсивный алгоритм (разложение по первой строке) для квадратных матриц произвольного размера $N \times N$.
* **Нахождение обратной матрицы ($A^{-1}$):** построение матрицы алгебраических дополнений (кофакторов), транспонирование в союзную матрицу и деление на определитель.
* **Деление матриц ($A / B$):** реализация деления через умножение левой матрицы на обратную к правой ($A \cdot B^{-1}$).

### 4. Интерактивный консольный интерфейс
* Удобное текстовое меню для управления программой.
* Интерактивный ввод матриц `M1` и `M2` с клавиатуры (ввод размеров и комплексных элементов).
* Защита от ошибок ввода и попыток выполнения операций с неинициализированными матрицами.

---

## 🚀 Структура проекта

* `Complex.java` — класс, описывающий комплексное число и операции над ним.
* `Matrix.java` — класс, реализующий структуру матрицы и всю линейную алгебру.
* `Main.java` — интерактивный консольный интерфейс (меню управления и тестирование).
