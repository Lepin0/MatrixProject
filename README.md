# 🧮 Complex Matrix Library

Консольное приложение на Java для работы с матрицами, состоящими из комплексных чисел.

## Основные возможности

* **Комплексные числа (`Complex`)**: хранение реальной и мнимой части, а также операции умножения и деления.
* **Базовые операции с матрицами**:
  * Сложение и вычитание матриц.
  * Транспонирование.
  * Умножение матриц друг на друга.
  * Умножение матрицы на комплексное число (скаляр).
* **Продвинутые операции**:
  * Вычисление определителя (для квадратных матриц).
  * Нахождение обратной матрицы.
  * Деление матриц.
* **Интерактивное меню**: удобное управление через консоль с возможностью ввода собственных матриц.

## Структура проекта

* `Complex.java` — класс комплексного числа.
* `Matrix.java` — класс для работы с матрицами и алгоритмами линейной алгебры.
* `Main.java` — консольное меню для запуска и тестирования.

## Как запустить
Просто откройте проект в **VS Code** и нажмите кнопку **Run** над методом `main` в файле `Main.java`.
